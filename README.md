# Projeto JPA com Hibernate e MySQL

Projeto de estudo desenvolvido para praticar **JPA puro**, utilizando **Hibernate** como implementação e **MySQL** como banco de dados, sem uso de frameworks como Spring Boot.

## 🛠 Tecnologias utilizadas
- Java 17
- JPA (javax.persistence)
- Hibernate 5.6
- Maven
- MySQL 8

🎯 Objetivo do projeto

Entender o funcionamento do JPA sem abstrações

Trabalhar diretamente com EntityManager

Gerenciar transações manualmente

Praticar mapeamento objeto-relacional

📌 Observações

Este projeto tem fins educacionais e foi desenvolvido para consolidar conceitos de persistência de dados no ecossistema Java.
